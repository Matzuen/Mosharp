# Mosharp 1.3.0

面向 10 万行仍可编辑的 Markdown 编辑器。

实时预览只装饰当前视口：标记默认隐藏，光标进入某个元素时才露出该元素的符号（加粗露 `**`、标题露 `#`），其余部分保持排版。公式、代码高亮、图片和图表只在滚进视口时挂上，滚出就卸掉。表格保持排版状态，直接在单元格里改字：`Tab` 跳格、末格自动加行、`Shift+Enter` 换行。侧栏搜索由后端遍历工作区，未展开的目录也能搜到文件名与正文。

Tauri 2 + SolidJS + CodeMirror 6。Windows 桌面应用（WebView2）。

## 特性

**编辑内核**

- 实时预览与源码模式共用同一份缓冲，`Ctrl+/` 只开关装饰，不重新排版全文
- 只装饰视口，重型块按可见性挂载/卸载；文档规模不影响输入路径
- 打字机模式、专注模式、正文栏宽三档（640 / 780 / 1080）
- 窗口缩放 `Ctrl+=` / `Ctrl+-` / `Ctrl+0`，比例记入偏好，下次启动沿用
- 撤销 / 重做，查找替换（大小写、全字、正则）
- 状态栏显示行数、字符数与字数（字数排除围栏代码、行内代码与 frontmatter）
- 内置 10 万行基准：帮助 → 10 万行基准

**写作**

- CommonMark + GFM：标题、列表、任务列表、引用、代码块、表格、分隔线
- `==高亮==`、上下标、脚注、emoji（`:` 触发选择器）、参考式链接
- 引用按 `>` 层级缩进并绘制多级竖线
- 选中文字出现浮动格式条；行首 `/` 打开插入菜单；段落左侧 `⋮` 菜单
- **表格浮动工具条**：右上「更多操作」菜单（插入/移动/删除行列、复制、格式化源码、删除表格），左下三个对齐图标；工具条只在光标进入表格后出现；`Esc` 或点外部关闭，`Ctrl+Enter` 插行、`Alt+方向键` 移动
- 表格单元格 `Tab` / `Shift+Tab` 逐格移动，末格 `Tab` 追加一行；`Shift+Enter` 在格内换行（源码里存为 `<br>`）；`Esc` 提交并离开表格
- 表格鼠标操作：拖表头右缘调列宽（按文档记在本地，重启仍在）、拖过多个单元格框选后 `Ctrl+C` 复制为 TSV / `Delete` 清空（`Shift+点击` 扩展选区）、拖行与列把手调整顺序；拖动时靠近窗口边缘会自动滚动
- 富文本复制，粘贴到邮件或聊天工具时保留格式
- 标题锚点跳转，中文标题可用（按住 `Ctrl` 再点）
- 选中文字后直接粘贴一个网址 → 自动包成 `[文字](网址)`
- 行首空行敲 `$$` 立刻生成公式块；敲 `` ``` `` 后输入语言再回车补出闭合围栏；围栏正文正好一行空行时，按退格整块删除（多余空行先逐行删）
- 输入围栏语言时弹出可选语言列表（`↑` `↓` 选择、`Enter` 采用）

**视口内的重块**

- KaTeX 行内公式与公式块；编辑公式块时源码以等宽卡片显示、**渲染结果同时保留在下方**；编辑行内公式时下方浮出渲染气泡，不占布局
- 代码块语法高亮 + 语言选择 + 悬停「复制」；相邻代码块之间有间隔
- 本地图片显示与拖拽调宽、剪贴板粘贴图片（存为 `assets/` 相对路径）
- Mermaid、Vega / Vega-Lite、PlantUML：滚进视口才渲染；编辑围栏时源码与渲染结果同时可见
- `[TOC]` 渲染成可点击目录；开头的 YAML front matter 折叠成一枚芯片，点开可编辑
- 文档里直接写的 HTML 会渲染：块级标签、以及段落里成对的**行内**标签（`文字 <b>粗</b> 文字`）；两者都先过允许列表过滤，点一下回到源码；```html 围栏仍按源码显示

**文件与会话**

- 原子保存：先写同目录临时文件再替换，写失败不留半截
- 编码识别与回写：UTF-8 / UTF-8 BOM / UTF-16 LE / UTF-16 BE / GBK；超过 64 MB 拒绝打开
- CRLF 文件保存后仍是 CRLF；YAML frontmatter 原样写回
- 外部程序改写文件后自动重载；自己也有未保存修改时不覆盖，改为在编辑器上方常驻提示条，让你选择重新加载或保留自己的修改
- 多标签，各自保留内容、脏状态、撤销历史、滚动位置、编码与行尾
- 启动恢复上次会话；关闭/丢弃未保存内容前写入恢复副本
- **双击 `.md` 直接打开该文件**（文件关联 + 单实例：已运行时并入现有窗口）；设置里可选「双击时恢复上次标签并打开该文件」，直接启动仍总是恢复会话
- **可选自动保存**：设置 ▸ 编辑里打开后，停止输入 1.2 秒写入磁盘（默认关闭）；若文件同时被外部改动，该标签会停止自动写入，避免覆盖别人的修改
- **侧栏搜索**：一次遍历同时给出文件名匹配与全文内容匹配，点内容结果跳到对应行；命中词高亮、`↑` `↓` 逐个跳转；支持区分大小写与正则；结果过多时明确提示只显示了前一部分
- **全库替换**：在内容结果下方输入替换词后整批替换，保留原编码；已打开的文件会被跳过；每个文件在改写前都会在恢复目录留一份「替换前-原名」的副本，编辑菜单可「撤销上次全库替换」
- **侧栏跟随当前文件**：切换标签后，树会自动展开它所在的文件夹并滚动到该行；工作区外的文件不做处理
- **恢复副本**：帮助 ▸ 恢复副本里可以按时间浏览、打开、删除恢复目录里的文件
- **外部冲突**：文件被别的程序改动时，编辑器上方常驻提示条，可选择「重新加载」或「保留我的修改并写入」
- **文件树写操作**：新建文件、新建文件夹、重命名、删除（只删空文件夹；有未保存修改的文件拒绝删除）
- `Ctrl+Shift+T` 重新打开刚关闭的标签（最多记 5 个）

**外观与语言**

- 15 套主题：8 套浅色（纸色、浅色、雅致、简白、作家、熊红、羊皮纸、Cadmium Light）、7 套深色（深色、午夜、夜航、极地、暖木、德古拉、Material Dark）
- 编辑器可指定字体与字号，优先于主题默认
- 7 种界面语言：简体中文、繁體中文、English、日本語、Deutsch、Français、Español
- Windows 自带拼写检查，语言可切换，可维护自定义词表

**导出**

- 带主题背景的 PDF（页边距跟随主题底色）
- 独立 HTML：KaTeX 样式与字体内联，离线打开公式不丢字形
- Word（.docx）
- 按阅读宽度的连续长图 PNG，超长自动编号分页；分页落在块边界，不把表格、代码块、图片切成两半
- 幻灯片：一条 `---` 一页，全屏放映，从光标所在页开始；可导出 16:9 幻灯片 PDF

## 开发

```bash
cd Mosharp                      # 仓库根目录（含 package.json 的那一层）
npm install
npm run tauri dev               # 桌面窗口，首次会编译 Rust
```

只调界面、不访问本机文件时：

```bash
npm run dev                     # 浏览器打开 http://localhost:1420
```

打开、保存、文件监听、导出 PDF 只在桌面窗口下可用。

开发模式下还有两样只给开发者用的东西，打包后不会出现：新建文档时的示例内容（正式版是空白文档），以及「帮助 → 10 万行基准」（生成器本身也会被 tree-shaking 掉）。判断依据是 Vite 的 `import.meta.env.DEV`。

**校验**

```bash
npm run check                                            # tsc --noEmit
npm test                                                 # 前端纯逻辑测试
cargo test --manifest-path src-tauri/Cargo.toml --lib     # Rust 测试
npm run e2e                                              # 浏览器端到端检查（需要本机 Chrome 或 Edge）
```

`npm run e2e` 会自己拉起 Vite（绑定 127.0.0.1:5199）、以无头模式启动本机 Chrome/Edge（调试端口 9333），通过 DevTools 协议用真实指针事件驱动界面，断言表格渲染、拖拽列宽、框选单元格、标记显隐、行内 HTML 等交互行为。它不在 `npm test` 里，因为它需要浏览器和两个空闲端口；端口可用 `MOSHARP_E2E_PORT` / `MOSHARP_E2E_DEBUG_PORT` 覆盖，浏览器路径可用 `MOSHARP_E2E_BROWSER` 指定。

纯逻辑测试覆盖不到指针行为——正是这套脚本发现了「多格框选从未生效」这类问题，所以改动交互后建议顺手跑一次。

`npm run tauri dev` 同时只允许一个实例运行——第二个会聚焦第一个窗口，这是单实例插件的预期行为。

## 打包

```bash
npm run tauri build
```

会依次执行 `npm run build`（前端）→ release 编译 Rust → 生成安装包。产物：

| 路径 | 说明 |
| :--- | :--- |
| `src-tauri/target/release/mosharp.exe` | 免安装可执行文件 |
| `src-tauri/target/release/bundle/nsis/Mosharp_1.3.0_x64-setup.exe` | NSIS 安装包（推荐，文件关联由它注册） |
| `src-tauri/target/release/bundle/msi/Mosharp_1.3.0_x64_en-US.msi` | MSI 安装包（需联网让 Tauri 下载 WiX） |

只要 NSIS、不想等 MSI：

```bash
npm run tauri build -- --bundles nsis
```

安装包会注册 `.md` / `.markdown` / `.mdown` / `.mkd` 关联。如果之前手动用「打开方式 → 始终使用」指定过别的程序，Windows 的 `UserChoice` 会压过安装器，需要重新选一次 Mosharp。

| 偏好设置 | `Ctrl+,` |
| 侧栏 | `Ctrl+\` |

## 已知限制

诚实列一下，避免预期落差：

- **光标仍在 Markdown 源码坐标上**。标记被装饰隐藏后，方向键和点击仍会踩进 `# `、`**` 这些字符；中文输入法的候选框按源码坐标定位，偶有偏移。光标所在行的标记本来就是可见的，所以标记永远可以直接编辑。
- **块级公式编辑时高亮整块源码**：光标落在 `$$` 块内，源码以等宽卡片显示，**渲染结果同时保留在下方**；行内元素则是逐元素露源码。
- 表格单元格换行以 `<br>` 存进源码，不是真正的多行单元格。
- 表格列宽存在本地（按文档记最近 64 张表），但 Markdown 文件本身不保存显示宽度：换一台机器或在别的编辑器里打开就是默认等宽。
- PlantUML 通过 plantuml.com 渲染，**图表源码会上传到该服务**；界面里有常驻说明，离线时无图。
- 全库搜索在后台线程遍历：命中数有上限（文件名 200、正文 200），超出时会提示只显示了前一部分。
- 全库替换有「撤销上次替换」（编辑菜单），但替换清单只记最近 10 次；更早的只能从恢复目录手动取回。
- 正则模式下暂不支持全库替换（需要反向引用语义）。
- 行内 HTML 只渲染配对的同一行标签，且长度上限 2000 字符；跨行、未闭合或超长的构造按源码显示。
- 从 HTML 块里恢复出来的代码块用简化样式（无语法高亮），因为高亮依附真实文本行。
- 15 套主题改的是颜色、字号与代码字体，排版骨架（段落间距、缩进）是固定的。
- 自动保存默认关闭；未落盘的「未命名」文档不会被自动保存。

## 技术栈

- [Tauri 2](https://tauri.app/) + WebView2（Rust 后端负责文件 IO、编码、监听、全文搜索、PDF 打印、单实例）
- [SolidJS](https://www.solidjs.com/)（界面）
- [CodeMirror 6](https://codemirror.net/)（编辑内核）
- [marked](https://marked.js.org/) + [KaTeX](https://katex.org/) + [Mermaid](https://mermaid.js.org/) + [Vega-Embed](https://vega.github.io/vega-lite/) + [html2canvas](https://html2canvas.hertzen.com/)（渲染与导出）

```
src/
  editor/          编辑内核：createEditor、装饰、实时预览、写作增强、输入补全
  editor/preview/  视口内的重块与交互（公式、图表、图片、表格、菜单、语言表、字数）
  export/          导出管线：article、docx、pages、slides、present、sanitize、katexCss
  shell/           外壳：菜单、命令面板、设置、会话、偏好、i18n
  themes/          主题目录与 15 套 CSS
  api/             Tauri 调用封装（文件、搜索）
scripts/
  test.mjs         纯逻辑测试运行器（node 逐文件执行 *.test.ts）
  e2e.mjs          浏览器端到端检查（Vite + CDP，见上文校验）
src-tauri/src/
  document.rs      读写、编码、原子保存、图片
  watch.rs         外部修改监听、恢复副本（写入 / 列出 / 删除）
  search.rs        工作区遍历：文件名与全文内容搜索
  startup.rs       命令行文件（双击打开）
  close_gate.rs    关闭前的未保存握手
  export_pdf.rs    WebView2 打印
  workspace.rs     目录列举、资源管理器定位、新建/重命名/删除
```
